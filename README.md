# District Lens downloads

Signed District Lens application updates. Download the Mac ZIP from Releases, extract it, quit District Lens, and replace the application. Existing library and Favorites remain in their normal locations.

App updates require an existing initialized District Lens library. No GitHub account is required to download public releases. Version 1.13.13 and later checks this feed directly.

This repository contains distribution files only. The development repository and reference library remain separate.
